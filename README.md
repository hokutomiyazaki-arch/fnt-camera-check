# fnt-camera-check（カメラでチェック・試し版）

スマホやパソコンのカメラで顔の点を読み取り、首・表情・目・舌の動きを数字にする試しの画面。
**カメラで本当に取れるかを確かめるためのもので、診断アプリの本体ではない。**

- 公開先：https://hokutomiyazaki-arch.github.io/fnt-camera-check/（カメラは https でないと起動しないので GitHub Pages）
- スタッフ表示：https://hokutomiyazaki-arch.github.io/fnt-camera-check/?staff=1（各段の数字・内部の判定・記録のコピーが出る）
- お客さんの画面（ふつうの URL）には判定も数字も出さない。記録はこの端末（localStorage の `fntcc_runs`・最新30件）に残る（2026-10-14 宮崎さん「最終的な判定結果はクライアントには見せないで、内部の方でデータを取っておく」）
- 道具：MediaPipe FaceLandmarker（tasks-vision 1.1.0・CDN・視線の値 blendshapes も使う）。映像は端末の外へ送らない
- 指示はいつも画面の真ん中に太く大きく出す（2026-10-14 宮崎さん）

## 流れ
0. 位置合わせ
1. 首の8の字：画面の ∞ を鼻先でなぞる（3周 → 反対回り3周）
2. 表情の左右差：口角・眉・目の閉じ
3. 目の準備：スマホを顔に近づけ、**目の大きさ**（目じり〜目がしら ÷ 映像の短い辺）が 0.13〜0.20 になると「OK ✓」→ 5か所の点で目の合わせ（横・たてそれぞれ、いちばん見分けのつく特徴を選ぶ）
4. 追従（スムーズパースート）：よこ・たて・ななめ2つ。向きごと（8方向）に点数
5. サッカード：8方向へ跳ぶ点。向きごとに反応の時間・速さ・届いた割合
6. 注視：真ん中の点を10秒見つめ、目の揺れ・流れ・外れた回数
7. 寄り目：画面の上の点を見たまま、スマホを鼻先へ近づける。先に外へ逃げた目
8. 舌：舌を出したコマから、舌の先が顔の中心線からどちらへ寄ったかを自動で出す

## 内部の判定（仮。宮崎さんが後で判定のしかたを伝える）
- 追従で 右・右上・右下 の点数が 左側より15以上低い → 右の皮質。逆 → 左の皮質。上下が左右より15以上低い → 中脳
- 目の合わせの「見分け」が2未満のときは判定しない（数字が信用できないため）
- 右・左はすべて本人から見た向き（インカメラの左右反転を直してある）

## 試験
- 舌：生成した写真3枚（まっすぐ・本人の右・本人の左）で正しく出た。舌を出していない顔では「判定できず」
- 追従・サッカード・注視：作った視線データで、右だけ弱い→右の皮質、上下だけ弱い→中脳、右への反応だけ遅い→右だけ遅く出ることを確かめた
