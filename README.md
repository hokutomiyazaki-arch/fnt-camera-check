# fnt-camera-check（カメラでチェック・試し版）

スマホやパソコンのカメラで顔の点を読み取り、首・表情・目・舌の動きを数字にする試しの画面。
**カメラで本当に取れるかを確かめるためのもので、診断アプリの本体ではない。**

- 公開先：https://hokutomiyazaki-arch.github.io/fnt-camera-check/（カメラは https でないと起動しないので GitHub Pages）
- スタッフ表示：https://hokutomiyazaki-arch.github.io/fnt-camera-check/?staff=1（各段の数字・内部の判定・記録のコピーが出る）
- お客さんの画面（ふつうの URL）には判定も数字も出さない。記録はこの端末（localStorage の `fntcc_runs`・最新30件）に残る（2026-10-14 宮崎さん「最終的な判定結果はクライアントには見せないで、内部の方でデータを取っておく」）
- 道具：MediaPipe FaceLandmarker（tasks-vision 1.1.0・CDN・視線の値 blendshapes も使う）。映像は端末の外へ送らない
- 指示はいつも画面の真ん中に太く大きく出す（2026-10-14 宮崎さん）

## 流れ（2026-10-14 に12段へ。瞳孔を外した）
0. 位置合わせ
1. ふだんの首の傾き：楽にした姿勢で5秒。目じりを結んだ線の傾き。スマホの傾き（加速度）も測り、区別できないときは読まない
2. 首の8の字：画面の ∞ を鼻先でなぞる（3周 → 反対回り3周）。始まる前に、動き始める向きを黄色い矢印で出す
3. 首の左右・上下
4. 表情の左右差：口角・眉・目の閉じ＋真顔での口角・眉の下がり＋目をギュッと閉じたときの目じりのしわの本数（写真から数える）
5. 目の準備：近さの確認 → 5か所の点で目の合わせ
6. 追従（スムーズパースート）
7. サッカード：向きごとの反応・速さ・届いた割合＋行き過ぎ（ハイパー）／届かない（ハイポ）
8. 注視
（瞳孔の大きさは 2026-10-14 に外した。宮崎さん「ちゃんと測れないなら測らなくても大丈夫」。ふつうの光の前のカメラでは、濃い茶色の黒目だと瞳孔の境が写らない。部品 stepPupil は残してある）
9. 寄り目：腕をのばした所から10秒かけて鼻先の指2本分（約5cm）まで。点が2つに見えたら止めてよい。終わりは「ピッ」と振動で知らせる
10. 舌
11. 質問：痛みが出やすい側・いまの痛みの側・聞こえにくい耳

## 内部の判定（仮。宮崎さんが後で判定のしかたを伝える）
- 追従で 右・右上・右下 の点数が 左側より15以上低い → 右の皮質。逆 → 左の皮質（カクつく方向＝同側の皮質。アドバンス教材 §7.1 で確定 2026-10-14）
- 追従の上下（上・下）の点数が左右より15以上低い → 中脳（2026-10-14 宮崎さん確定）
- 見立て：動眼神経（寄り目が悪い側）は中脳として読む。寄り目と上下の追従が両方弱い → 中脳の働き低下。首の8の字で「気持ち悪い」（少し・かなり）→ 前庭の問題を疑う（2026-10-14 宮崎さん）
- サッカード：届かない → 反対側の皮質・行き過ぎる → 同じ側の小脳（アドバンス教材 §7.1 で確定）。跳ぶまでの遅さ・速さの左右差は記録のみ
- 点を見つめる：揺れ（よこ・たての大きい方）0.08 以上か、外れ3回以上 → 小脳の働きの低下の可能性（側は未判定。宮崎さんの返事待ち）。しきい値は仮
- 目の合わせの「見分け」が2未満のときは判定しない（数字が信用できないため）
- 右・左はすべて本人から見た向き（インカメラの左右反転を直してある）

## 試験
- 舌：生成した写真3枚（まっすぐ・本人の右・本人の左）で正しく出た。舌を出していない顔では「判定できず」
- 追従・サッカード・注視：作った視線データで、右だけ弱い→右の皮質、上下だけ弱い→中脳、右への反応だけ遅い→右だけ遅く出ることを確かめた
- 経緯：~/dev/marketing-playbook/assessments/FNT店舗_コンセプトメイキング/（P8b・P8c）

## 首の検査の内部の読み（2026-10-14 宮崎さん・しきい値は仮）
- 8の字（1周8秒）：全体についていけない → 小脳虫部・前庭機能。真ん中→左下＝右の前半規管、→右上＝右の後半規管、→右下＝左の前半規管、→左上＝左の後半規管（左上は並びからの補完。宮崎さんの文が途中で切れていた。宮崎さんが後で判定ルールを送ってきたら、それで上書き）
- 首の左右・上下（1往復6秒×3）：左→右でずれる・遅い＝右の水平半規管、右→左＝左の水平半規管、上＝両方の後半規管、下＝両方の前半規管
- 「右」の半規管 → 右の小脳、「左」 → 左の小脳。くり返し（3回中2回以上）ずれた向きだけ読む。全部が同じように悪いときは半規管ではなく小脳虫部・前庭機能
- 試験：作った鼻先の動き（左下だけずれる・右上だけ・左上だけ・右→左だけ遅い・左→右だけ遅い・下だけ遅い・全く追わない）で、それぞれ正しい半規管が出て、ふつうの動きでは何も出なかった

## 見立て（2026-10-14 宮崎さん・スタッフ表示の最後に出る。しきい値は仮）
- サッカード（**提案中・宮崎さんの OK 待ち**。BDC「サッカード」ページID 3980）：ある向きへ届かない＝反対側の皮質（右へ届かない→左の皮質）。行き過ぎる＝同じ側の小脳。右へ届かない＋左へ行き過ぎ＝左の小脳のかたち。2回以上・4割以上くり返したときだけ
- 首の傾き：傾いた側の前庭器官
- 舌が寄った側の舌下神経／口角・眉が下がった側・しわが少ない側の顔面神経／寄りが悪い側（先に逃げた目）の動眼神経／聞こえにくい側の内耳神経
- 脳神経の側＝眼球運動で出た皮質の側 → その側の皮質の問題。逆 → 脳神経の問題
- 痛みが出やすい側 → その側の PMRF。いまの痛みが PMRF と同じ側 → PMRF の問題。さらに皮質の低下とも同じ側 → 皮質の低下が影響している PMRF の問題
- 試験：作ったデータで、首の傾き（右5°→右・左4°→左・1°→なし・スマホも傾いている→読まない）、サッカード（右へ届かない→左の皮質・左へ行き過ぎ→左の小脳・両方→左の小脳・ふつう→なし）、瞳孔（同じ→なし・左が大きい→左・右が大きい→右・境が見えない→判定できず）、しわ（右4本・左1本→左の顔面神経）、見立ての組み合わせ、質問から最後の画面まで

## カメラが止まったとき（2026-10-14）
- しばらく置くと画面が消える・別のアプリに移るなどでカメラが止まる。画面に戻ったとき・映像が2秒止まったとき・カメラが切れたときに、自動で開き直す
- 使っている間は画面を消さない（Wake Lock）。最初の「始める」で10秒カメラが開かなければ、理由を出してボタンを戻す
