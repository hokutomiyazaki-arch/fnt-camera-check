# fnt-camera-check（カメラでチェック・試し版）

スマホやパソコンのカメラで顔の点を読み取り、首・表情・目・舌の動きを数字にする試しの画面。
**カメラで本当に取れるかを確かめるためのもので、診断アプリの本体ではない。**

- 公開先：https://hokutomiyazaki-arch.github.io/fnt-camera-check/（カメラは https でないと起動しないので GitHub Pages）
- **トレーナー用だけ**（2026-10-18 宮崎さん「クライアント用は不要。ちゃんと結果が出せるトレーナー用だけ」）。どの URL でも各段の数字・内部の判定・見立て・記録のコピーが出る（前の `?staff=1` は付けても付けなくても同じ）。記録はこの端末（localStorage の `fntcc_runs`・最新30件）に残る
- **検査を選んで測れる**（2026-10-18 宮崎さん「毎回最初から検査するのは大変。トップページで『このテスト』って選べるように」）：トップに「全部を通して検査する」と、検査ごとのチェック欄。選んだものだけを並び順に測り、最後の検査のあと記録の画面へ。目の検査は目の準備を省いても、始める前に自動で目の合わせをする。前に選んだものは端末に覚える。直接のリンク：`?t=side,vor` のように key（tilt・side・eight・neck・face・prep・pursuit・okn・vor・conv・tongue・jaw・svv・ask）を並べる。記録の `plan` に測った検査が入る
- **ファネル用の入り口**（2026-10-18）：`?t=side,noseA,svv&back=/check` のように `back`（同じサイトの中の道のり）を付けて開くと、お客さん向け（数字・判定を出さない・トレーナー用の札なし・トップは「チェックを始める」だけ）で選んだ検査を流し、終わったら記録を `fntcc_runs` に残して `back#cc=<started>` へ戻る。からだの神経チェック（`~/dev/fnt-optin/check.html`）が `go.functional-neuro-training.com/cc/start`（Vercel が GitHub Pages のこのアプリをそのまま中継）から呼ぶ。**ここを直せば /check の検査も同じに変わる**
  - 🔴 鼻先を合わせる①の「どこからズレとするか」はアプリにまだ無いので、/check 側で仮に 4.5°（`check.html` の `CFG.jpe`）としている。ここに鼻先の線引きを入れたら、/check もそれに合わせる（`CFG.jpe` を消して、アプリの読みを使う）
- この「トップで選んで、選んだ段だけ流す」作り（index.html の `TESTS`・`planNext`）は、ほかの診断LPにも移せる
- 道具：MediaPipe FaceLandmarker（tasks-vision 1.1.0・CDN・視線の値 blendshapes も使う）。映像は端末の外へ送らない
- 指示はいつも画面の真ん中に太く大きく出す（2026-10-14 宮崎さん）

## 流れ（2026-10-14 に15段へ。瞳孔を外し、口の開け方・のどの奥・肩すくめを足した）
0. 位置合わせ
1. ふだんの首の傾き：楽にした姿勢で5秒。目じりを結んだ線の傾き。スマホの傾き（加速度）も測り、区別できないときは読まない
1b. 首を横に倒す（側屈の可動域・2026-10-16 追加。いまの番号では「2.」で、後ろの段は1つずつ繰り下がった）：スマホは動かさず右・左へ倒せるところまで倒して2.5秒×2回ずつ。目じりの線の傾き＋スマホの傾き（ジャイロ）で手が傾いた分を足し戻す。数字の記録だけで読みは未定（10°以上の左右差を「倒れにくい側」として残す・仮）。回旋・上下はカメラだと端で顔を読めず角度も縮むので入れていない
2. 首の8の字：画面の ∞ を鼻先でなぞる（3周 → 反対回り3周）。始まる前に、動き始める向きを黄色い矢印で出す
3. 首の左右・上下
4. 表情の左右差：口角・眉・目の閉じ＋真顔での口角・眉の下がり＋目をギュッと閉じたときの目じりのしわの本数（写真から数える）
5. 目の準備：近さの確認 → 5か所の点で目の合わせ
6. 追従（スムーズパースート）
（7. サッカード・8. 注視は 2026-10-16 に外した。下の「外した検査」）
（瞳孔の大きさは 2026-10-14 に外した。宮崎さん「ちゃんと測れないなら測らなくても大丈夫」。ふつうの光の前のカメラでは、濃い茶色の黒目だと瞳孔の境が写らない。部品 stepPupil は残してある）
9. 寄り目：腕をのばした所から10秒かけて鼻先の指2本分（約5cm）まで。点が2つに見えたら止めてよい。終わりは「ピッ」と振動で知らせる
10. 舌
11. 口の開け方（2026-10-14 追加）：口をゆっくり開けて閉じる×3。下あごの先が顔の中心線からずれる向き
12. のどの奥（口蓋・2026-10-14 追加）：大きく口を開けて「あっ、あっ、あっ」。ライト（つけられない端末は画面を白くして照らす）、写真を自動で4枚撮り、横線と真ん中の線を重ねて見せる。後ろのカメラ＋ライトでも撮れる（人に撮ってもらうとき）
13. 肩をすくめてキープ（2026-10-14 追加）：スマホを立てて置き、楽にした肩の高さ → すくめて30秒キープ。体の点（PoseLandmarker）で両肩の高さを取る
16. 盲点マップ（2026-10-31 追加）：壁から約30cm・スマホを壁に当て、盲点マップ（/moten-map/?embed=1）を全画面で開いて右目・左目の8点を取る。結果（面積・形・BDCの読み）は RUN.bs、盲点が10%以上大きい目の反対側の皮質を内部の判定に1件足す（右目の盲点＝左の皮質）。お客さん用（/check）には入れていない（2026-10-31 宮崎さん：/check への組み込みは取り消し、カメラでチェックに足す）
17. 質問：痛みが出やすい側・いまの痛みの側・聞こえにくい耳

## 内部の判定（仮。宮崎さんが後で判定のしかたを伝える）
- 追従で 右・右上・右下 の点数が 左側より15以上低い → 右の皮質。逆 → 左の皮質（カクつく方向＝同側の皮質。アドバンス教材 §7.1 で確定 2026-10-14）
- 追従の上下（上・下）の点数が左右より15以上低い → 中脳（2026-10-14 宮崎さん確定）
- 見立て：動眼神経（寄り目が悪い側）は中脳として読む。寄り目と上下の追従が両方弱い → 中脳の働き低下。首の8の字で「気持ち悪い」（少し・かなり）→ 前庭の問題を疑う（2026-10-14 宮崎さん）
- サッカード：届かない → 反対側の皮質・行き過ぎる → 同じ側の小脳（アドバンス教材 §7.1 で確定）。跳ぶまでの遅さ・速さの左右差は記録のみ
- 点を見つめる：揺れ（よこ・たての大きい方）0.08 以上か、外れ3回以上（スクエアウェーブジャーク）→ 小脳虫部（両側）（2026-10-14 宮崎さん確定）。ほかの検査の小脳・前庭の所見は加算材料として見立てに並べる。しきい値は仮
- 見立ての先頭に「重なり」：同じ所（左右の皮質・中脳・小脳虫部・前庭・左右の PMRF）に重なった所見の数を多い順に出す。重なりが多い所ほど問題がありそうと読む（2026-10-14 宮崎さん）
- 目の合わせの「見分け」が2未満のときは判定しない（数字が信用できないため）
- 右・左はすべて本人から見た向き（インカメラの左右反転を直してある）

## 試験
- 舌：生成した写真3枚（まっすぐ・本人の右・本人の左）で正しく出た。舌を出していない顔では「判定できず」
- 追従・サッカード・注視：作った視線データで、右だけ弱い→右の皮質、上下だけ弱い→中脳、右への反応だけ遅い→右だけ遅く出ることを確かめた
- 経緯：~/dev/marketing-playbook/assessments/FNT店舗_コンセプトメイキング/（P8b・P8c）

## 首の検査の内部の読み（2026-10-14 宮崎さん・しきい値は仮）
- 8の字（1周8秒）：全体についていけない → 小脳虫部・前庭機能。真ん中→左下＝右の前半規管、→右上＝右の後半規管、→右下＝左の前半規管、→左上＝左の後半規管（左上は並びからの補完。宮崎さんの文が途中で切れていた。宮崎さんが後で判定ルールを送ってきたら、それで上書き）
- 首の左右・上下（1往復6秒×3）：左→右でずれる・遅い＝右の水平半規管、右→左＝左の水平半規管、上＝両方の後半規管、下＝両方の前半規管
- 「右」の半規管 → 右の小脳、「左」 → 左の小脳。くり返し（3回中2回以上）ずれた向きだけ読む。全部が同じように悪いときは半規管ではなく小脳虫部・前庭機能
- 試験：作った鼻先の動き（左下だけずれる・右上だけ・左上だけ・右→左だけ遅い・左→右だけ遅い・下だけ遅い・全く追わない）で、それぞれ正しい半規管が出て、ふつうの動きでは何も出なかった

## 見立て（2026-10-14 宮崎さん・スタッフ表示の最後に出る。しきい値は仮）
- サッカード（**提案中・宮崎さんの OK 待ち**。BDC「サッカード」ページID 3980）：ある向きへ届かない＝反対側の皮質（右へ届かない→左の皮質）。行き過ぎる＝同じ側の小脳。右へ届かない＋左へ行き過ぎ＝左の小脳のかたち。2回以上・4割以上くり返したときだけ
- 首の傾き：傾いた側の前庭器官
- 舌が寄った側の舌下神経／口角・眉が下がった側・しわが少ない側の顔面神経／寄りが悪い側（先に逃げた目）の動眼神経／聞こえにくい側の内耳神経
- 脳神経の側＝眼球運動で出た皮質の側 → その側の皮質の問題。逆 → 脳神経の問題
- 痛みが出やすい側 → その側の PMRF。いまの痛みが PMRF と同じ側 → PMRF の問題。さらに皮質の低下とも同じ側 → 皮質の低下が影響している PMRF の問題
- サッカードの小脳（2026-10-14 宮崎さん「小脳も関わるはず。BDC で調べて」。BDC「サッカード」「小脳虫部＝室頂核」）：届かないだけのときは反対側の皮質と読み、反対側の小脳の可能性を添える。斜め 右上・左下で行き過ぎ・届かないが多い → 右の小脳／左上・右下 → 左の小脳（反対の組より2回以上多いとき）。上下へ跳ぶ途中で横へずれる（跳ぶ幅の20%以上・半分以上の回）→ ずれる側の小脳。上に行き過ぎ・下に届かない（半球中間帯）は左右の目を分けて測っていないので読まない
- 口の開け方：下あごが目じりの間の長さの 0.05 以上・3回中2回以上同じ側へ → その側の三叉神経（運動核・橋）（BDC「CN5 三叉神経運動核」：問題のある方向に顎がずれる。顎関節の構造でもずれるので一概には言えない）
- のどの奥：スタッフが写真を見て「上がりが悪い（低い）アーチ」を押す → その側の舌咽・迷走神経（延髄）（BDC「CN9・10 口蓋」。2つは分けられないので合わせて読む）。自動の判定はしない。写真は新しい5回分だけ端末に残す
- 肩すくめ：キープ中に下がった量の左右差が肩の幅の 0.025 以上 → 先に下がる側の副神経（延髄）（BDC「CN11」）。楽にしたときに 0.03 以上下がっている肩も添える
- 三叉神経＝橋、舌咽・迷走・副神経＝延髄として、皮質と逆の側なら「右の延髄」などの重なりに数える（皮質と同じ側なら、ほかの脳神経と同じく皮質に重ねる）
- 試験：作ったデータで、首の傾き（右5°→右・左4°→左・1°→なし・スマホも傾いている→読まない）、サッカード（右へ届かない→左の皮質・左へ行き過ぎ→左の小脳・両方→左の小脳・ふつう→なし）、瞳孔（同じ→なし・左が大きい→左・右が大きい→右・境が見えない→判定できず）、しわ（右4本・左1本→左の顔面神経）、見立ての組み合わせ、質問から最後の画面まで

## カメラが止まったとき（2026-10-14）
- しばらく置くと画面が消える・別のアプリに移るなどでカメラが止まる。画面に戻ったとき・映像が2秒止まったとき・カメラが切れたときに、自動で開き直す
- 使っている間は画面を消さない（Wake Lock）。最初の「始める」で10秒カメラが開かなければ、理由を出してボタンを戻す

## 音声・見本・練習（2026-10-14）
- 画面の真ん中の指示を読み上げる。声は ElevenLabs（eleven_v3・リョウ＝AI音読と同じ声）で前もって作った `voice/*.mp3`。無い文だけ端末の声で読む。右上の「🔊 音声オン／🔇 音声オフ」でいつでも切れる（端末に覚える）。カウントダウンと「何周目」は変わった数字だけ読む
- 🔴 指示の文を変えたら `python3 tools/voice_build.py` で足りない音声を作る（`--dry` で一覧と字数だけ）。スタッフ表示のコンソールに「[voice] 音声ファイルなし」が出たら、その文を voice_build.py の EXTRA に足す
- 左上の「↺ 最初からやり直し」で、テストの最中でもいまのテストを最初から始め直せる
- 首の8の字・首の左右上下は、始める前の枠に線画の見本（顔が鼻先で線をなぞる動き）を流す。8の字は「まず練習する（1周ずつ・記録しない）」を先にできる
- ∞・線のガイドは画面の真ん中（横）に固定し、たては鼻の高さ。始める前の画面から出しておく（見本と見出しは上、説明はボタンの上）。測っている間の指示は下寄り。線には黒いふちを敷く

## 外した検査（2026-10-16 宮崎さん）
- サッカード（跳ぶ点を見る）：わざと行き過ぎ・届かないを何度やっても読めなかった。行き過ぎて戻る動きは0.1秒以内で、カメラ（1秒10〜25コマ）では1〜2コマにしか写らず、顔の点の読み取りが均して消す
- 注視（点を見つめる）：見ていたスクエアウェーブジャーク（0.5〜数度外れて0.2秒ほどで戻る）も同じく小さく速い動きで、読み取りの揺れに埋もれる
- どちらも関数（stepSacc・stepFix）は index.html に残し、検査の流れ・判定・見立て・記録の一覧からは外した。番号は 9.流れる縞以降を2つずつ詰めた（全13段）

- **判定：首の位置感覚**（2026-10-18 宮崎さん）：①（目を閉じて真ん中へ戻す）は、向き（右・左・上・下。ななめは2つに数えて3回ずつ）の平均が **4.5°** を超えたら「首の位置感覚の乱れ」。②は同じ数字を参考に出すだけ。基準は角度なので距離で変わらず、cm は距離×tan：76cm の的で 6.0cm、スマホが顔から30cmなら画面の上で 2.4cm（距離は黒目の大きさから目安を出す）。カメラが小さく読む分は戻して比べる（回旋÷0.8・上下÷0.5）。出典：Carrick CNS10「Tests of Vestibular Function Pt.2」[0:16:31–0:21:47]・note packet p.49–50／Revel 1991（PMID 2009044）／Dugailly 2015（PMID 26438174）。note packet の PMID 26538174 は打ち間違い
